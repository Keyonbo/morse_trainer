# Roadmap

## v1.3 — current code snapshot

- [x] Pico + MicroPython
- [x] Main MORSE key and passive piezo
- [x] SSD1306 OLED
- [x] Manual keying and fixed-timing Morse decoder
- [x] International letters A–Z and numerals 0–9
- [x] Message accumulation and word gaps
- [x] RESET function in firmware
- [x] External LED control in firmware
- [ ] End-to-end hardware confirmation for latest RESET and LED changes

## Planned (not implemented)

- [ ] LED / reset hardware confirmation and mounting
- [ ] Hardware MENU and OK buttons
- [ ] Free Keying / Decoder mode selection
- [ ] Listening: device plays random characters for ear training
- [ ] Practice: scoring and progress
- [ ] WPM adjustment via potentiometer
- [ ] Character timing calibration and debouncing
- [ ] Optional Cyrillic display font and Russian Morse table
- [ ] Enclosure and safe stand-alone battery power

## Non-goals for now

- RF transmission: this is an audio/electronic practice device, **not** a radio transmitter.
- Cloud service or network connectivity.
